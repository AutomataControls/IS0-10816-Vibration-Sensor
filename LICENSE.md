## Purpose ##
Professional-grade vibration monitoring system for industrial equipment health
analysis. Implements ISO 10816-3 standards for rotating machinery with multi-port
architecture supporting up to 32 sensors per system.

## Features ##
- Multi-port monitoring for sensors with identical Modbus addresses
- ISO 10816-3 compliant vibration severity zones (A-D)
- Real-time web dashboard with trend analysis
- SQLite database with 7-day automatic retention
- Node-RED integration for industrial IoT
- Equipment-specific profiles (pumps, motors, compressors, fans)
- Professional desktop application for Linux
- REST API for third-party integration
